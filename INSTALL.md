# Install guide

## What is inside
This pack contains:
- `README.md` ready to use
- an `assets/` folder with local SVG ornaments and badges
- a preview image

## How to use it on your GitHub profile
1. Open the repository whose name matches your GitHub username.
2. Replace its current `README.md` with the `README.md` included here.
3. Upload the entire `assets/` folder to the same repository root.
4. Commit the changes.
5. Wait a few seconds and refresh your GitHub profile page.

## Notes
- The README uses **only local SVG files** for the decorative system.
- The `<picture>` tags provide dark/light variants for the main ornaments.
- The publication list preserves the titles, translations, journal names, DOI/ISBN links, and the order you provided.
- The design is intentionally based on **ornamental SVGs + real text**, which is more durable and maintainable than a full illustrative banner.
